EV充電記録 Webアプリ

■ 主な機能
- 日付、充電場所、急速/普通、充電器出力、開始%、終了%、時間、充電量、金額、走行距離、メモを記録
- 増加% と 円/kWh を自動計算
- 充電履歴の検索・絞り込み
- 月別集計
- 充電場所別集計
- 充電器出力別比較
- CSV書き出し
- 端末内保存（localStorage）
- PWA対応の基本構成

■ 使い方
1. index.html をWebサーバー上に置いて開いてください。
2. iPhoneではSafariで開き、「共有」→「ホーム画面に追加」でアプリのように使えます。
3. 記録データはブラウザ内に保存されます。ブラウザデータを消すと記録も消えるため、定期的にCSV書き出しをおすすめします。

※ service worker / PWA は file:// では動作しないため、Web公開環境でご利用ください。
